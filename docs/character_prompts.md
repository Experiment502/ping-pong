# 角色重製：ChatGPT 指令

每個角色畫 12 張圖（4 個方向 × 跨步、站立、跨步），放進 `assets/char_frames/<資料夾名稱>/`。
已完成：桌球社學姊（`15_female_referee`）。

## 流程

1. **每個角色開一個新的 ChatGPT 對話。**
2. 貼上「設定」，把【角色說明】換成第三節裡那個角色的說明，【頭頂】換成表格裡的數字。
3. 依序貼上 12 個姿勢的指令，一次一段，每段畫一張。
4. 每張畫完都貼一次「檢查」。有問題就請它重畫那一張。
5. 第 1 張是定稿。不喜歡就先重畫第 1 張，滿意了再繼續，不然後面 11 張都會照著它畫。
6. 照「存檔」的檔名存好，跟 Claude 說，先放進測試頁看走路的樣子。

## 五、對戰用的姿勢（會在對戰模式當對手的角色才需要）

對戰時對手站在球桌對面、**面向玩家**，所以這 12 張都是正面。跟走路的 12 張在**同一個對話**裡接著畫（ChatGPT 才記得這個角色），存在同一個資料夾。

先貼一次說明：

```
接下來畫這個角色打桌球的姿勢，一樣一次一張，規則跟前面相同（1024×1024、純洋紅背景、只畫一個人、置中、腳底在 90%、人物大小跟第 1 張一樣）。
這些姿勢都是「站在球桌對面、面向看圖的人」的正面，球拍一直拿在右手（也就是畫面的左邊）。
先不要畫，回答「了解」就好。
```

再依序貼這 12 段：

```
準備 1：桌球的準備姿勢。雙腳打開比肩膀寬，膝蓋微彎，身體稍微往前傾，右手的球拍舉在身體前方、腰的高度，左手也舉在身體前方。眼睛看著前方。
```
```
準備 2：以「準備 1」為基礎，只把身體稍微往下壓一點（膝蓋彎多一點），其他都不變。這是準備時上下輕輕晃動的另一格。
```
```
移動 1：以「準備 1」為基礎，往旁邊移動的側併步：雙腳張得很開，身體保持面向看圖的人，球拍還是舉在身體前方。
```
```
移動 2：以「準備 1」為基礎，側併步的另一格：雙腳併攏靠近，身體保持面向看圖的人，球拍舉在身體前方。
```
```
正手 1：正手引拍。身體往右轉（往畫面的左邊轉），右手把球拍往後拉到身體右後方、腰的高度，重心在右腳。
```
```
正手 2：正手揮拍到一半。右手把球拍往前揮，球拍在身體右前方，手臂快要伸直。
```
```
正手 3：正手擊球的瞬間。右手手臂往前伸直，球拍在身體正前方偏右、胸口的高度，身體轉回面向看圖的人。
```
```
正手 4：正手收拍。球拍揮到左肩前面、額頭的高度，身體往左轉，重心移到左腳。
```
```
反手 1：反手引拍。右手把球拍收到肚子前面、偏左邊（畫面的右邊），拍面朝前，手肘彎曲。
```
```
反手 2：反手揮拍到一半。球拍從肚子前面往前推出，在身體正前方。
```
```
反手 3：反手擊球的瞬間。右手往前、往右推出去，手臂快要伸直，球拍在身體右前方、胸口的高度。
```
```
反手 4：反手收拍。手臂伸直，球拍停在右前方、肩膀的高度，然後準備收回。
```
