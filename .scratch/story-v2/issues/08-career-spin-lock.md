# 08: 冠軍之路一開始不能打旋轉球

**What to build:** 冠軍之路裡，上旋、下旋、側旋一開始全部鎖住，只能打平擊。還沒學會時，往上或往下滑一樣能把對手的旋轉球接回去，只是你打出去的球不會帶旋轉。對手只會用你已經學會的旋轉：學校的對手幾乎都打平擊。一般比賽和練習模式不受影響，什麼都能打。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 冠軍之路裡沒學會的旋轉打不出來，球路變成平擊
- [ ] 沒學會時往上、往下滑仍然能接回旋轉球
- [ ] 對手不會打你還沒學會的旋轉
- [ ] 一般比賽、練習模式的旋轉照舊
- [ ] 學會哪些旋轉會記在存檔裡（這張先預設全部沒學會；舊存檔也是）
- [ ] 自動測試頁加入這幾項並通過
