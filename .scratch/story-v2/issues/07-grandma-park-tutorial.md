# 07: 老奶奶在公園的操作教學

**What to build:** 早上第一次經過社區公園時，老奶奶在公園。她借你一支球拍，教你最基本的打法：手指從旁邊往中間滑過球。在公園的桌球桌練習接 3 球平擊，成功後把球拍還給她。玩家可以跟她說「我會了」直接跳過。她會順口提到她認識你爸爸，留下伏筆。之後老奶奶回到她自己家。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 第一次到公園時老奶奶會找你說話
- [ ] 選練習：打一段只有平擊的練習，成功 3 球就結束；失敗可以重來，不扣錢、不磨損球拍
- [ ] 選跳過：直接結束
- [ ] 結束後球拍不會留在你身上（還沒去學校拿球拍時仍然沒有球拍）
- [ ] 對話提到她認識爸爸
- [ ] 只會發生一次
- [ ] 自動測試頁加入這幾項並通過
