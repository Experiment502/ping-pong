# 01: 冠軍之路的自動測試頁

**What to build:** 在 repo 的測試資料夾裡放一個測試頁：用瀏覽器開整個遊戲，用腳本操作冠軍之路，從開新遊戲一路玩下去，並把結果列出來（每一項 OK 或 FAIL）。比賽用遊戲現有的自動對打模式（bot）打完。之後每一張工作單都用這個測試頁驗收。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 打開測試頁就會自動跑完，最後顯示通過幾項、失敗幾項
- [ ] 涵蓋目前的路線：房間 → 客廳 → 社區街道 → 公園 → 校門 → 操場 → 教學樓 → 一樓走廊（辦公室、桌球體育館）→ 二樓教室 → 市區道路 → 市區中心
- [ ] 涵蓋目前的學校關卡：教練給球拍 → 勁敵挑戰 → 三位老師 → 主任 → 校長
- [ ] 只檢查玩家看得到的結果（在哪張地圖、對話內容、存檔內容），不檢查程式內部的寫法
- [ ] 現在的遊戲跑起來全部通過
