# 09: 老奶奶教新的球種

**What to build:** 每一級賽事（校際賽、地區比賽、全國比賽）奪冠後，手機收到老奶奶的訊息「有空來我家一趟」。去老奶奶家，她講一段爸爸以前的故事，問你想學哪一種球（只列出還沒學的，每種附一句說明），畫面轉到公園的桌球桌，她送指定的球路讓你練，成功 3 次就學會。不學新球種也能報名下一級，只是比較難。

**Blocked by:** 04, 07, 08

**Status:** ready-for-agent

- [ ] 奪冠後收到老奶奶的訊息
- [ ] 去她家可以從還沒學的球種裡選一種
- [ ] 練習成功 3 次後學會，比賽裡就能打出那種旋轉
- [ ] 練習失敗可以重來，不扣錢、不磨損球拍
- [ ] 三種都學完後，她不會再教（第四次拜訪是另一張工作單）
- [ ] 沒去學也能報名下一級
- [ ] 自動測試頁加入這幾項並通過
